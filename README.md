# Daily-Task-Scheduler

## Overview

Developed a GUI-based Daily Task Scheduler using Java Swing in Eclipse IDE to manage daily tasks with features like task addition, deletion, completion tracking, and real-time task viewing.

## Features

* Add tasks
* Delete tasks
* Mark tasks as completed
* GUI-based interface using Java Swing
* Real-time task display

## Technologies Used

* Java
* Java Swing
* Eclipse IDE
* OOP Concepts
